You Are the Memory!

Meet LSTM: Long Short-Term Memory. Help your team remember useful details, update old information, and choose what to use in an answer.

Your group becomes an LSTM

Work alone or in a group of 4–5. Read one story card at a time. Decide what to keep on your memory board before revealing the next card.

Forget gate

How much old information should stay? Remove a note when it is no longer useful.

Input gate

Which new information should enter memory? Add a short note.

Output gate

What stored information should be made available for the current answer?

A fourth student keeps the memory board. A fifth student can read the cards.

Your challenge: keep up to three short notes. Talk through your decisions. You will know the general task before you begin, but the exact question comes at the end.

This is a simplified analogy. Real LSTMs process numerical representations of sequences. Their gates learn during training and can let information through partially. They do not consciously choose facts. The three-note limit is only a game rule.
Instructor notes

Allow around 20–25 minutes. Assign roles, project the guided story, then let groups complete the new practice story. Encourage explanations before clicking. There is no need to enter names.

The memory board represents the cell state. The output gate controls what part of the updated cell state contributes to the hidden state; a downstream output layer can use that hidden state to produce an answer. Selecting a note here simplifies that process.

Optional comparison: on paper, keep only the first three facts with no updates. Repeat the parcel story. The stale code shows why updating matters. This artificial restriction does not represent all other AI models.
